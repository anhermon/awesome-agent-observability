# Social preview

`social-preview.png` is the 1280×640 image for this repository's GitHub social preview (Settings → General → Social preview). GitHub has no API for that upload, so after merging, upload the PNG there for it to appear on shared links.

`social-preview.svg` is the source. The PNG was rendered from it with Liberation Sans (Bold 72 / Regular 40 / Regular 32) at the same layout coordinates.
