# Security policy

Awesome Agent Observability is a list of links and contains no executable code, so the realistic security issues are:

- an entry that links to malicious, compromised, or typosquatted software;
- a listed project that has become unsafe (hijacked repository, malicious release, leaked credentials).

Report these privately through the repository's Security tab ("Report a vulnerability"), not a public issue. Include the entry, the evidence, and the date you observed it. Confirmed cases are removed from the list as soon as they are verified.
